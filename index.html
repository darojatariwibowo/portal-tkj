Modul Pembelajaran: Konfigurasi VLAN & Trunking (Semester 1)

Tujuan Pembelajaran: Peserta didik mampu merancang segmentasi jaringan lokal menggunakan Virtual LAN (VLAN) pada perangkat router/switch manageable serta menguji konektivitas antar-VLAN.

Jobsheet Praktik: Dasar Konfigurasi VLAN di MikroTik

Salin perintah CLI berikut ke terminal Winbox / RouterOS:

/interface vlan add name=VLAN10-GURU vlan-id=10 interface=ether2
/interface vlan add name=VLAN20-SISWA vlan-id=20 interface=ether2
/ip address add address=192.168.10.1/24 interface=VLAN10-GURU
/ip address add address=192.168.20.1/24 interface=VLAN20-SISWA

Project Based Learning (PjBL): Infrastruktur Jaringan Lab Sekolah

Studi Kasus: Sekolah membangun gedung lab baru yang membutuhkan pemisahan jaringan antara ruang Guru, Lab Komputer 1, dan Hotspot Siswa dalam satu jalur kabel utama.
